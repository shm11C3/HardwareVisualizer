# Windowsセンサーサービスのリリースノート

サービスを導入するリリース向けの掲載用文案です。リリースの公開を示すものではありません。
[英語版](windows-sensor-service.md)。

WindowsのMSIでは、Program Files配下への新規インストール・更新にセンサーサービスが
含まれるようになります。サイレント更新でも追加の選択は不要です。PawnIOと対応モジュールが
導入済みであれば、HardwareVisualizer本体を一般権限で起動したまま、CPUの温度・消費電力と
マザーボードのセンサー値を取得できます。導入・修復には引き続き管理者の承認が必要です。
PawnIOは任意の外部ドライバーであり、同意なしに新規導入することはありません。

保存済みの「管理者として起動」は維持します。これらのセンサーのためだけに有効にしていた
場合は、**設定 → 高度な設定**でオフにしてアプリを終了し、通常起動してください。
一部のストレージ正常性情報など、他の特権機能では取得できる情報が減る場合があります。
現在のプロセスの権限は、設定を変更しただけでは下がりません。ご自身で作成した最高権限の
スケジュールタスクや互換性設定は、別途変更してください。

NSIS版・ポータブル版は導入済みの互換サービスを利用できますが、サービスの導入には
保護されたMSI版が必要です。サービスがなくても通常の監視と利用可能なフォールバックは
継続します。更新が成功した場合に、一律の移行CTAは表示しません。実際のセンサー取得と
代替取得を試しても画面で必要な値が不足する場合は、既存の取得失敗の案内からセンサー設定へ
進み、状態確認や修復を行えます。
